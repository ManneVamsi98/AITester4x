## definition
/goal — Set objective agent work toward. /goal improve login speed. Use /goal clear to remove, /goal status to see current. Agent prioritize steps matching goal.

/compact — Squash conversation history into summary when context window fill up. Session stays but old detail condensed. Same as auto-compact but manual. /compact-mode control aggressiveness.

/mcp — Manage MCP (Model Context Protocol) server connections. MCP gives agent extra tools — read files, query DBs, call APIs via external server. /mcp add, /mcp list, /mcp remove servers.
