# Research ML, VS DL, VS AI
• AI Engineer → Uses AI 
• ML Engineer → Builds ML models 
• DL Engineer → Builds deep neural networks.


### AI Engineer vs ML Engineer vs DL Engineer
• AI Engineer: Builds AI-powered applications using existing AI/Foundation models, APIs, and tools.

• ML Engineer: Trains, deploys, and maintains machine learning models using business data.

• DL Engineer: Designs and trains deep neural networks for complex data like text, images, audio, and video.
