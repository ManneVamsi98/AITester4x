# QABuddy.ai — hosted (Vercel)

Static UI + one serverless function. Retrieval runs against **Qdrant Cloud** (a free cluster with
**Cloud Inference**, so embeddings are computed server-side — no separate embedding vendor) and
answers are generated by **Groq**.

```
index.html ──POST /api/ask──► Qdrant Cloud (embed + search) ──► Groq ──► {answer, citations}
```

This is the **hosted demo**. It is dense-only and uses the free English model
`sentence-transformers/all-MiniLM-L6-v2`. The self-hosted app in the parent folder keeps the fuller
stack (bge-m3 hybrid + reranker).

## Environment variables (set on Vercel, not in a file)

| Variable | Example |
|---|---|
| `QDRANT_URL` | `https://<cluster>.cloud.qdrant.io` |
| `QDRANT_API_KEY` | *(Qdrant Cloud API key)* |
| `QDRANT_COLLECTION` | `qabuddy` |
| `CLOUD_EMBED_MODEL` | `sentence-transformers/all-MiniLM-L6-v2` |
| `GROQ_KEY` | *(Groq API key)* |
| `GROQ_MODEL` | `openai/gpt-oss-120b` |
| `TOP_K` | `8` |

## Deploy

```bash
# from this web/ folder
vercel link --yes --project qabuddy
vercel env add QDRANT_URL production       # https://<cluster>.cloud.qdrant.io
vercel env add QDRANT_API_KEY production
vercel env add GROQ_KEY production
# optional: QDRANT_COLLECTION, CLOUD_EMBED_MODEL, GROQ_MODEL, TOP_K
vercel --prod
```

The index is populated from the parent folder with `python scripts/ingest_cloud.py`.
